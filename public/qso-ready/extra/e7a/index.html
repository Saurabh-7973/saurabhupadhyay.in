E7A: Digital circuits: digital circuit principles and logic circuits; classes of logic elements; positive and negative logic; frequency dividers; truth tables

Group E7A of the Amateur Extra pool (2024–2028) has 11 active questions. One of them is on every Amateur Extra exam. Each is shown word for word; open it to see the correct answer and our explanation.

E7A01

Which circuit is bistable?

  1. A An AND gate
  2. B An OR gate
  3. C A flip-flop
  4. D A bipolar amplifier
Show the answer and explanation

Correct answer: C. A flip-flop

Why C is right. C. A flip-flop has two stable states and stays in either one until an input tells it to change.

Bistable means two states that each hold steady on their own. A flip-flop cross-connects two gates or transistors so its output feeds back and locks itself high or low. That memory makes it the basic building block of counters and registers. Plain gates have no memory; their outputs follow the inputs at every instant.

Why not A? An AND gate has no feedback, so it cannot hold a state once its inputs change.

E7A02

What is the function of a decade counter?

  1. A It produces one output pulse for every 10 input pulses
  2. B It decodes a decimal number for display on a seven-segment LED display
  3. C It produces 10 output pulses for every input pulse
  4. D It decodes a binary number for display on a seven-segment LED display
Show the answer and explanation

Correct answer: A. It produces one output pulse for every 10 input pulses

Why A is right. A. A decade counter steps through ten states and then rolls over, giving one carry pulse for every ten pulses in.

Decade means ten. The counter goes from 0 to 9, and on the tenth pulse it resets to 0 and sends a carry pulse. That divides the input frequency by 10. Chaining counters gives division by 100, 1,000 and so on, which is handy in frequency counters.

Why not B? Turning a number into segment patterns is the job of a decoder or display driver, not the counter.

E7A03

Which of the following can divide the frequency of a pulse train by 2?

  1. A An XOR gate
  2. B A flip-flop
  3. C An OR gate
  4. D A multiplexer
Show the answer and explanation

Correct answer: B. A flip-flop

Why B is right. B. A flip-flop wired to toggle changes state once per input pulse, so its output makes one full cycle for every two input pulses.

In toggle mode, each clock edge flips the output: high, then low. Two input pulses produce one full output cycle, so the output frequency is half the input. This is the simplest digital frequency divider.

Why not A? An XOR gate has no memory, so it cannot keep track of every second pulse.

E7A04

How many flip-flops are required to divide a signal frequency by 16?

  1. A 4
  2. B 6
  3. C 8
  4. D 16
Show the answer and explanation

Correct answer: A. 4

Why A is right. A. Each flip-flop halves the frequency, and four halvings give 2 x 2 x 2 x 2 = 16.

Chain the flip-flops so each one's output clocks the next. Every stage divides by 2, so n stages divide by 2 to the power n. Sixteen is 2 to the fourth power.

division ratio = 2^n
2^n = 16
n = log2(16) = 4
= 4

Why not D? Sixteen flip-flops would divide by 2 to the 16th power, which is 65,536.

E7A05

Which of the following circuits continuously alternates between two states without an external clock signal?

  1. A Monostable multivibrator
  2. B J-K flip-flop
  3. C T flip-flop
  4. D Astable multivibrator
Show the answer and explanation

Correct answer: D. Astable multivibrator

Why D is right. D. An astable multivibrator has no stable state, so it keeps flipping between its two states on its own.

Astable means not stable. Two switching stages with timing capacitors push each other back and forth, and resistor and capacitor values set how long each state lasts. The result is a free-running square wave with no clock needed. A monostable needs a trigger, and flip-flops need a clock or other input.

Why not A? A monostable rests in one state and changes only briefly after a trigger.

E7A06

What is a characteristic of a monostable multivibrator?

  1. A It switches temporarily to an alternate state for a set time
  2. B It produces a continuous square wave
  3. C It stores one bit of data
  4. D It maintains a constant output voltage, regardless of variations in the input voltage
Show the answer and explanation

Correct answer: A. It switches temporarily to an alternate state for a set time

Why A is right. A. A monostable has one resting state; a trigger flips it to the other state for a time set by a resistor and capacitor, then it returns.

Mono means one: there is only one stable state. Each trigger produces one output pulse of fixed length. These one-shot circuits stretch short pulses, clean up switch bounce and create time delays.

Why not C? Storing a bit needs two stable states, which is what a flip-flop has.

E7A07

What logical operation does a NAND gate perform?

  1. A It produces a 0 at its output only if all inputs are 0
  2. B It produces a 1 at its output only if all inputs are 1
  3. C It produces a 0 at its output if some but not all inputs are 1
  4. D It produces a 0 at its output only if all inputs are 1
Show the answer and explanation

Correct answer: D. It produces a 0 at its output only if all inputs are 1

Why D is right. D. NAND is AND followed by NOT, and AND gives 1 only when every input is 1, so NAND gives 0 only in that case.

For a two-input NAND, inputs 00, 01 and 10 give 1, and input 11 gives 0. Any 0 at an input forces the output to 1. NAND gates can be combined to build every other logic function, which is one reason they are so common.

Why not B? An output of 1 only when all inputs are 1 describes a plain AND gate.

E7A08

What logical operation does an OR gate perform?

  1. A It produces a 1 at its output if any input is 1
  2. B It produces a 0 at its output if all inputs are 1
  3. C It produces a 0 at its output if some but not all inputs are 1
  4. D It produces a 1 at its output if all inputs are 0
Show the answer and explanation

Correct answer: A. It produces a 1 at its output if any input is 1

Why A is right. A. An OR gate needs only one input at 1 to make its output 1; the output stays 0 only when every input is 0.

Two-input OR truth table: 00 gives 0, while 01, 10 and 11 all give 1. Picture two switches wired side by side to a lamp: closing either one lights it.

Why not D? An output of 1 for all-zero inputs describes a NOR gate, the opposite of OR.

E7A09

What logical operation is performed by a two-input exclusive NOR gate?

  1. A It produces a 0 at its output only if all inputs are 0
  2. B It produces a 1 at its output only if all inputs are 1
  3. C It produces a 0 at its output if one and only one of its inputs is 1
  4. D It produces a 1 at its output if one and only one input is 1
Show the answer and explanation

Correct answer: C. It produces a 0 at its output if one and only one of its inputs is 1

Why C is right. C. Exclusive NOR outputs 1 when its two inputs match, so a single 1 among them, a mismatch, gives 0.

XOR outputs 1 when the inputs differ. XNOR inverts that: 00 gives 1 and 11 gives 1, while 01 and 10 give 0. That makes it a one-bit equality checker.

Why not D? An output of 1 when exactly one input is 1 is plain XOR, not XNOR.

E7A10

What is a truth table?

  1. A A list of inputs and corresponding outputs for an op-amp
  2. B A list of inputs and corresponding outputs for a digital device
  3. C A diagram showing logic states when the digital gate output is true
  4. D A table of logic symbols that indicate the logic states of an op-amp
Show the answer and explanation

Correct answer: B. A list of inputs and corresponding outputs for a digital device

Why B is right. B. A digital device's inputs and outputs can only be 1 or 0, so every input combination and its result can be listed row by row.

With n inputs there are 2 to the n combinations, so a two-input gate has four rows. Reading across a row tells you exactly what the device does. It works for gates, flip-flops and larger logic, but not for op-amps, whose outputs vary smoothly instead of being 1 or 0.

Why not A? Op-amps are analog parts with outputs that vary smoothly, so a table of 1s and 0s does not describe them.

E7A11

What does “positive logic” mean in reference to logic devices?

  1. A The logic devices have high noise immunity
  2. B High voltage represents a 1, low voltage a 0
  3. C The logic circuit is in the “true” condition
  4. D 1s and 0s are defined as different positive voltage levels
Show the answer and explanation

Correct answer: B. High voltage represents a 1, low voltage a 0

Why B is right. B. Positive logic is a naming convention: the more positive of the two voltage levels is read as 1, whatever the actual voltages are.

A logic circuit only sees voltage levels, so a convention is needed to say which level means 1. Positive logic assigns 1 to high; negative logic assigns 1 to low. The same circuit acts as an AND gate in one convention and an OR gate in the other.

Why not D? Both levels can be positive voltages in either convention; what matters is which level counts as 1.
