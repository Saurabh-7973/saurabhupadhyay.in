E2E: Operating methods: digital modes and procedures for HF

Group E2E of the Amateur Extra pool (2024–2028) has 13 active questions. One of them is on every Amateur Extra exam. Each is shown word for word; open it to see the correct answer and our explanation.

E2E01

Which of the following types of modulation is used for data emissions below 30 MHz?

  1. A DTMF tones modulating an FM signal
  2. B FSK
  3. C Pulse modulation
  4. D Spread spectrum
Show the answer and explanation

Correct answer: B. FSK

Why B is right. B. FSK fits in a narrow HF channel and is allowed there, while spread spectrum and pulse are not authorized below 30 MHz.

In FSK, the transmitter shifts between frequencies to send ones and zeros, as RTTY does. Many HF data modes use some form of FSK.

Why not D? Spread spectrum is not permitted below 30 MHz.

E2E02

Which of the following synchronizes WSJT-X digital mode transmit/receive timing?

  1. A Alignment of frequency shifts
  2. B Synchronization of computer clocks
  3. C Sync-field transmission
  4. D Sync-pulse timing
Show the answer and explanation

Correct answer: B. Synchronization of computer clocks

Why B is right. B. WSJT-X modes send and receive in fixed time slots, so the computer clock must be set accurately.

Modes such as FT8 start each transmission at a set second of the minute. If your clock is off by more than about a second, other stations cannot decode you, and you cannot decode them. Most users sync their clock to an internet time server or GPS.

Why not C? The timing comes from the computer clock, not a transmitted sync field.

E2E03

To what does the "4" in FT4 refer?

  1. A Multiples of 4 bits of user information
  2. B Four-tone continuous-phase frequency shift keying
  3. C Four transmit/receive cycles per minute
  4. D All these choices are correct
Show the answer and explanation

Correct answer: B. Four-tone continuous-phase frequency shift keying

Why B is right. B. FT4 is named for its modulation: four tones, with smooth, continuous-phase shifts between them.

Shifting without phase jumps keeps the signal clean and narrow. FT4's shorter cycles suit contests.

Why not C? FT4 cycles are 7.5 seconds long, so a minute holds eight of them, not four.

E2E04

Which of the following is characteristic of the FST4 mode?

  1. A Four-tone Gaussian frequency shift keying
  2. B Variable transmit/receive periods
  3. C Seven different tone spacings
  4. D All these choices are correct
Show the answer and explanation

Correct answer: D. All these choices are correct

Why D is right. D. FST4 uses four-tone Gaussian FSK, offers several transmit and receive period lengths, and has a range of tone spacings, so all choices are correct.

Gaussian FSK smooths the tone changes so the signal stays narrow. Longer periods let FST4 decode weaker signals. Wider tone spacing helps on paths with more frequency spreading.

E2E05

Which of these digital modes does not support keyboard-to-keyboard operation?

  1. A WSPR
  2. B RTTY
  3. C PSK31
  4. D MFSK16
Show the answer and explanation

Correct answer: A. WSPR

Why A is right. A. WSPR is a beacon mode that sends only call sign, grid square and power, so you cannot type messages to another station.

WSPR (Weak Signal Propagation Reporter) is for testing propagation. Stations send fixed reports and others report what they hear to an online map. There is no free-text exchange.

Why not B? RTTY is a classic typing mode.

E2E06

What is the length of an FT8 transmission cycle?

  1. A It varies with the amount of data
  2. B 8 seconds
  3. C 15 seconds
  4. D 30 seconds
Show the answer and explanation

Correct answer: C. 15 seconds

Why C is right. C. FT8 locks transmissions to clock-timed slots, and the standard slot is 15 seconds, four to a minute.

Each station sends during one slot, then listens in the next. The signal lasts about 12.6 seconds, leaving time to decode and reply.

Why not D? 30 seconds is a full transmit and receive pair, not one cycle.

E2E07

How does Q65 differ from JT65?

  1. A Keyboard-to keyboard operation is supported
  2. B Quadrature modulation is used
  3. C Multiple receive cycles are averaged
  4. D All these choices are correct
Show the answer and explanation

Correct answer: C. Multiple receive cycles are averaged

Why C is right. C. Q65 can average several receive cycles, adding up a weak repeated message until it decodes.

If the same message comes in over several cycles, Q65 adds them together. Noise is random and tends to cancel, while the signal adds up. This helps on weak paths such as EME.

Why not B? Q65 uses tones (FSK), not quadrature modulation.

E2E08

Which of the following HF digital modes can be used to transfer binary files?

  1. A PSK31
  2. B PACTOR
  3. C RTTY
  4. D AMTOR
Show the answer and explanation

Correct answer: B. PACTOR

Why B is right. B. PACTOR can send binary files because it checks each block and resends any with errors.

PACTOR uses ARQ (automatic repeat request). The receiving station checks every block and asks for a resend when one is bad. That gives error-free data, which binary files require.

Why not C? RTTY has no error checking and uses a code with only letters and figures.

E2E09

Which of the following HF digital modes uses variable-length character coding?

  1. A RTTY
  2. B PACTOR
  3. C MT63
  4. D PSK31
Show the answer and explanation

Correct answer: D. PSK31

Why D is right. D. PSK31 uses varicode, where common letters get short codes and rare ones get longer codes.

Giving short codes to letters like e and t speeds up typical text. RTTY uses fixed 5-bit codes for every character. PSK31 is a narrow keyboard mode often used on HF.

Why not A? RTTY uses a fixed-length 5-bit code.

E2E10

Which of these digital modes has the narrowest bandwidth?

  1. A MFSK16
  2. B 170 Hz shift, 45-baud RTTY
  3. C FT8
  4. D PACTOR IV
Show the answer and explanation

Correct answer: C. FT8

Why C is right. C. FT8 is the narrowest of these, at about 50 Hz wide.

FT8 moves among eight closely spaced tones. MFSK16 is about 316 Hz wide. 170 Hz shift RTTY is around 250 Hz. PACTOR IV uses about 2.4 kHz.

Why not D? PACTOR IV is the widest of the four.

E2E11

What is the difference between direct FSK and audio FSK?

  1. A Direct FSK modulates the transmitter VFO
  2. B Direct FSK occupies less bandwidth
  3. C Direct FSK can transmit higher baud rates
  4. D All these choices are correct
Show the answer and explanation

Correct answer: A. Direct FSK modulates the transmitter VFO

Why A is right. A. Direct FSK shifts the transmitter's own oscillator, while audio FSK feeds tones into an SSB transmitter.

With direct FSK, the transmitter's VFO (variable frequency oscillator) is moved by the data line. With audio FSK (AFSK), a computer makes audio tones, and the SSB transmitter shifts them up to RF. Done right, both make the same signal on the air.

Why not B? Both methods can give the same bandwidth.

E2E12

How do ALE stations establish contact?

  1. A ALE constantly scans a list of frequencies, activating the radio when the designated call sign is received
  2. B ALE radios monitor an internet site for the frequency they are being paged on
  3. C ALE radios send a constant tone code to establish a frequency for future use
  4. D ALE radios activate when they hear their signal echoed by back scatter
Show the answer and explanation

Correct answer: A. ALE constantly scans a list of frequencies, activating the radio when the designated call sign is received

Why A is right. A. ALE radios are addressed by call sign, so they scan their channel list and wake up only when they hear their own address.

ALE (automatic link establishment) radios also test which channel works best. When called, they stop and set up the link on that channel.

Why not D? ALE uses scanning and addressing, not backscatter echoes.

E2E13

Which of these digital modes has the highest data throughput under clear communication conditions?

  1. A MFSK16
  2. B 170 Hz shift, 45 baud RTTY
  3. C FT8
  4. D PACTOR IV
Show the answer and explanation

Correct answer: D. PACTOR IV

Why D is right. D. PACTOR IV adapts to the path, using fast modulation and compression on a clean channel, so it moves far more data than the others.

RTTY and MFSK16 are slow keyboard modes. FT8 sends only short fixed messages.

Why not C? FT8 sends only short messages each 15 seconds.
