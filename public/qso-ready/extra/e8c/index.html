E8C: Digital signals: digital communication modes; information rate vs. bandwidth; error correction; constellation diagrams

Group E8C of the Amateur Extra pool (2024–2028) has 15 active questions. One of them is on every Amateur Extra exam. Each is shown word for word; open it to see the correct answer and our explanation.

E8C01

What is Quadrature Amplitude Modulation or QAM?

  1. A A technique for digital data compression used in digital television which removes redundancy in the data by comparing bit amplitudes
  2. B Transmission of data by modulating the amplitude of two carriers of the same frequency but 90 degrees out of phase
  3. C A method of performing single sideband modulation by shifting the phase of the carrier and modulation components of the signal
  4. D A technique for analog modulation of television video signals using phase modulation and compression
Show the answer and explanation

Correct answer: B. Transmission of data by modulating the amplitude of two carriers of the same frequency but 90 degrees out of phase

Why B is right. B. Two carriers a quarter cycle apart can be separated again at the receiver, so each can carry its own amplitude, which is what QAM does.

Two carriers 90 degrees apart can be separated again at the receiver, so each can carry its own amplitude. Together their two amplitudes pick one point on a grid. Each grid point stands for a group of bits. More points mean more bits per symbol, but they sit closer together and need a cleaner signal.

Why not C? Phase-shifting the carrier and audio is the phasing method of making SSB, which is analog voice, not QAM.

E8C02

What is the definition of symbol rate in a digital transmission?

  1. A The number of control characters in a message packet
  2. B The maximum rate at which the forward error correction code can make corrections
  3. C The rate at which the waveform changes to convey information
  4. D The number of characters carried per second by the station-to-station link
Show the answer and explanation

Correct answer: C. The rate at which the waveform changes to convey information

Why C is right. C. Symbol rate counts how many times per second the signal changes state, since each change is one unit of information.

A symbol is one state of the waveform, such as a tone, a phase or an amplitude. The transmitter holds a symbol, then switches to the next. The number of switches per second is the symbol rate, measured in baud. One symbol can carry one bit or several bits, depending on how many states the mode uses.

Why not D? Characters per second depend on the code and bits per symbol, so they are not the symbol rate.

E8C03

Why should the phase of a PSK signal be changed at the zero crossing of the RF signal?

  1. A To minimize bandwidth
  2. B To simplify modulation
  3. C To improve carrier suppression
  4. D All these choices are correct
Show the answer and explanation

Correct answer: A. To minimize bandwidth

Why A is right. A. Flipping phase when the wave passes through zero avoids a sudden jump in voltage, and sudden jumps spread energy over a wide band.

If the phase flips at a peak, the voltage snaps from top to bottom in an instant. A sharp edge like that contains many high-frequency parts, so the signal splatters wide. If the flip happens as the wave crosses zero, the voltage stays smooth and the signal stays narrow.

Why not C? Carrier suppression depends on the balance of the modulator, not on when the phase changes.

E8C04

What technique minimizes the bandwidth of a PSK31 signal?

  1. A Zero-sum character encoding
  2. B Reed-Solomon character encoding
  3. C Use of sinusoidal data pulses
  4. D Use of linear data pulses
Show the answer and explanation

Correct answer: C. Use of sinusoidal data pulses

Why C is right. C. PSK31 shapes its amplitude with smooth sine-shaped pulses, so phase changes happen gently and the spectrum stays narrow.

At each phase reversal, PSK31 fades the signal down to zero and back up along a cosine-shaped curve. There are no sharp corners in the envelope, so very little energy spreads beyond the main signal. The result is a signal only a few tens of hertz wide. Straight-line pulse edges have corners that widen the spectrum.

Why not D? Linear pulses have sharp corners where they start and stop, which adds bandwidth instead of saving it.

E8C05

What is the approximate bandwidth of a 13-WPM International Morse Code transmission?

  1. A 13 Hz
  2. B 26 Hz
  3. C 52 Hz
  4. D 104 Hz
Show the answer and explanation

Correct answer: C. 52 Hz

Why C is right. C. Morse at 13 WPM keys at about 10.4 baud, and a well-shaped CW signal needs about 5 times its baud rate, near 52 Hz.

Rule of thumb: Morse speed in baud is about 0.8 times the words per minute. A CW signal's bandwidth is roughly that baud rate times a shaping factor K. K = 5 is the usual value for normal keying that holds up under fading. Together these give bandwidth of about 4 times the WPM.

BW = K × baud, with baud = 0.8 × WPM and K = 5
baud = 0.8 × 13 = 10.4
BW = 5 × 10.4 Hz
= 52 Hz

Why not A? 13 Hz matches the WPM number but ignores the sidebands the keying creates.

E8C06

What is the bandwidth of an FT8 signal?

  1. A 10 Hz
  2. B 50 Hz
  3. C 600 Hz
  4. D 2.4 kHz
Show the answer and explanation

Correct answer: B. 50 Hz

Why B is right. B. FT8 uses eight tones 6.25 Hz apart, so its signal fills about 50 Hz.

FT8 is a weak-signal digital mode that sends one of eight audio tones at a time. Each tone is 6.25 Hz from the next, and 8 times 6.25 Hz is 50 Hz. Many FT8 stations fit side by side within a 3 kHz SSB receiver passband, which is why one screen can show dozens of signals.

Why not D? 2.4 kHz is about the width of a voice SSB signal or receiver passband, not one FT8 signal.

E8C07

What is the bandwidth of a 4,800-Hz frequency shift, 9,600-baud ASCII FM transmission?

  1. A 15.36 kHz
  2. B 9.6 kHz
  3. C 4.8 kHz
  4. D 5.76 kHz
Show the answer and explanation

Correct answer: A. 15.36 kHz

Why A is right. A. FSK bandwidth is about the baud rate plus 1.2 times the shift, which gives 9600 + 5760 = 15,360 Hz.

A frequency-shift signal needs room for the two tones and for the sidebands made by switching between them. A common estimate, from the FCC's necessary-bandwidth formula, is baud rate plus 1.2 times the total shift. Change hertz to kilohertz at the end.

BW = baud + 1.2 × shift
BW = 9600 + 1.2 × 4800 Hz
BW = 9600 + 5760 = 15,360 Hz
= 15.36 kHz

Why not B? 9.6 kHz counts only the baud rate and leaves out the frequency shift.

E8C08

How does ARQ accomplish error correction?

  1. A Special binary codes provide automatic correction
  2. B Special polynomial codes provide automatic correction
  3. C If errors are detected, redundant data is substituted
  4. D If errors are detected, a retransmission is requested
Show the answer and explanation

Correct answer: D. If errors are detected, a retransmission is requested

Why D is right. D. ARQ (automatic repeat request) fixes errors by having the receiver ask for a block again when its check fails.

Each data block carries a short check value. The receiving station recalculates it. If it matches, the station sends an acknowledgment. If it does not match, the station asks for a repeat, and the sender transmits the block again. This needs a two-way link, unlike forward error correction, which repairs errors from extra data sent up front.

Why not C? Using extra data sent along with the message to fix errors is forward error correction, not ARQ.

E8C09

Which digital code allows only one bit to change between sequential code values?

  1. A Binary Coded Decimal Code
  2. B Extended Binary Coded Decimal Interchange Code
  3. C Extended ASCII
  4. D Gray code
Show the answer and explanation

Correct answer: D. Gray code

Why D is right. D. Gray code orders its values so that moving to the next one flips exactly one bit, which avoids false readings mid-change.

In plain binary, going from 3 (011) to 4 (100) flips three bits at once. If a sensor reads during that change, it may catch a mix and report a wrong number. Gray code avoids that: neighbors always differ by one bit. Rotary position encoders often use it.

Why not A? Binary Coded Decimal stores each decimal digit in four bits and often flips several bits between values.

E8C10

How can data rate be increased without increasing bandwidth?

  1. A It is impossible
  2. B Increasing analog-to-digital conversion resolution
  3. C Using a more efficient digital code
  4. D Using forward error correction
Show the answer and explanation

Correct answer: C. Using a more efficient digital code

Why C is right. C. A more efficient code sends the same message with fewer bits, so more information moves through the same bandwidth.

Bandwidth limits how many symbols per second you can send. You can still carry more information by using fewer bits per character, or by fitting more bits into each symbol. Both are choices of coding. Forward error correction does the opposite: it adds extra bits to protect the data, which lowers the useful data rate.

Why not D? Forward error correction adds redundant bits, so it reduces the data rate for a given bandwidth.

E8C11

What is the relationship between symbol rate and baud?

  1. A They are the same
  2. B Baud is twice the symbol rate
  3. C Baud rate is half the symbol rate
  4. D The relationship depends on the specific code used
Show the answer and explanation

Correct answer: A. They are the same

Why A is right. A. Baud is the unit for symbols per second, so a symbol rate and a baud rate are the same number.

A signal sending 300 symbols each second runs at 300 baud. What can differ is the bit rate. If each symbol carries two bits, the bit rate is 600 bits per second while the baud rate stays 300. Mixing up baud and bits per second is the common mistake.

Why not D? The code changes the bit rate, not the relationship between baud and symbol rate.

E8C12

What factors affect the bandwidth of a transmitted CW signal?

  1. A IF bandwidth and Q
  2. B Modulation index and output power
  3. C Keying speed and shape factor (rise and fall time)
  4. D All these choices are correct
Show the answer and explanation

Correct answer: C. Keying speed and shape factor (rise and fall time)

Why C is right. C. Faster keying and sharper on-off edges both add sidebands, so speed and rise and fall time set CW bandwidth.

A CW signal is a carrier switched on and off. Each switch creates sidebands. More switches per second push them farther out. Very quick rise and fall times add even more distant sidebands, heard as key clicks. Gently shaped edges and moderate speed keep the signal narrow.

Why not B? Output power changes how loud the signal is, not how wide; modulation index applies to FM and PM.

E8C13

What is described by the constellation diagram of a QAM or QPSK signal?

  1. A How many carriers may be present at the same time
  2. B The possible phase and amplitude states for each symbol
  3. C Frequency response of the signal stream
  4. D The number of bits used for error correction in the protocol
Show the answer and explanation

Correct answer: B. The possible phase and amplitude states for each symbol

Why B is right. B. A constellation diagram plots each allowed symbol as a point whose angle is its phase and whose distance from center is its amplitude.

QPSK has four points, all at the same distance from the center but at four phases. 16-QAM has sixteen points in a grid, using several amplitudes and phases. On a live signal, noise smears each dot into a cloud. If the clouds touch, the receiver starts making errors.

Why not C? Frequency response is shown on a plot of level against frequency, not on a phase and amplitude map.

E8C14

What type of addresses do nodes have in a mesh network?

  1. A Email
  2. B Trust server
  3. C Internet Protocol (IP)
  4. D Talk group
Show the answer and explanation

Correct answer: C. Internet Protocol (IP)

Why C is right. C. Ham mesh networks run standard internet protocols, so each node is reached by an Internet Protocol (IP) address.

A mesh network links radio nodes, often modified Wi-Fi routers on ham frequencies, so data can hop node to node. Because they use the same networking methods as the internet, each node gets an IP address. Computers, cameras and servers connected to a node can then exchange data across the mesh.

Why not D? Talk groups are used to route digital voice on systems like DMR, not to address mesh nodes.

E8C15

What technique do individual nodes use to form a mesh network?

  1. A Forward error correction and Viterbi codes
  2. B Acting as store-and-forward digipeaters
  3. C Discovery and link establishment protocols
  4. D Custom code plugs for the local trunking systems
Show the answer and explanation

Correct answer: C. Discovery and link establishment protocols

Why C is right. C. Mesh nodes find their neighbors and set up links on their own, using discovery and link-establishment protocols.

When a node powers up, it announces itself and listens for others. Nodes share which neighbors they can hear and how good each link is. From that, each node builds a map of routes. If a node goes off the air, the others notice and route around it with no manual setup.

Why not B? Store-and-forward digipeaters relay packets along set paths; they do not build a self-organizing network.
