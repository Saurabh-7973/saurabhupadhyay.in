G8C: Digital emission modes

Group G8C of the General pool (2023–2027) has 15 active questions. One of them is on every General exam. Each is shown word for word; open it to see the correct answer and our explanation.

G8C01

Withdrawn by NCVEC on 2024-11-08. It is not used on exams.

G8C02

Which digital mode is used as a low-power beacon for assessing HF propagation?

  1. A WSPR
  2. B MFSK16
  3. C PSK31
  4. D SSB-SC
Show the answer and explanation

Correct answer: A. WSPR

Why A is right. A. WSPR stations send slow, low-power beacons that others decode far below the noise and report online, which maps where a band is open.

Each WSPR transmission carries the call sign, location and power, so the reports show who heard whom and how strongly.

Why not C? PSK31 is a keyboard chat mode, not a beacon system.

G8C03

What part of a packet radio frame contains the routing and handling information?

  1. A Directory
  2. B Preamble
  3. C Header
  4. D Trailer
Show the answer and explanation

Correct answer: C. Header

Why C is right. C. The header holds the routing and handling information in a packet frame.

A packet is like a letter in an envelope. The header is the address on the envelope: who it is from, who it is to, and how to pass it along. The data that follows is the letter itself.

Why not D? A trailer, if present, holds error-check data at the end of the frame.

G8C04

Which of the following describes Baudot code?

  1. A A 7-bit code with start, stop, and parity bits
  2. B A code using error detection and correction
  3. C A 5-bit code with additional start and stop bits
  4. D A code using SELCAL and LISTEN
Show the answer and explanation

Correct answer: C. A 5-bit code with additional start and stop bits

Why C is right. C. Five bits give 32 patterns, enough for letters plus a shift code for figures, and start and stop bits mark each character's edges.

Shift codes switch between a letters set and a figures set. Baudot is the code used for RTTY.

Why not A? A 7-bit code with parity describes ASCII, not Baudot.

G8C05

In an ARQ mode, what is meant by a NAK response to a transmitted packet?

  1. A Request retransmission of the packet
  2. B Packet was received without error
  3. C Receiving station connected and ready for transmissions
  4. D Entire file received correctly
Show the answer and explanation

Correct answer: A. Request retransmission of the packet

Why A is right. A. NAK means 'not acknowledged': the receiver found errors, so it asks for that packet again.

ARQ stands for automatic repeat request. After each packet, the receiver checks it for errors. A good packet gets ACK, meaning acknowledged.

Why not B? A packet received without error gets an ACK, not a NAK.

G8C06

What action results from a failure to exchange information due to excessive transmission attempts when using an ARQ mode?

  1. A The checksum overflows
  2. B The connection is dropped
  3. C Packets will be routed incorrectly
  4. D Encoding reverts to the default character set
Show the answer and explanation

Correct answer: B. The connection is dropped

Why B is right. B. ARQ software allows only a set number of retries, and when they run out it gives up and ends the link.

ARQ keeps resending a packet until it gets through. If conditions are so poor that it fails again and again, the link is dropped rather than retrying forever.

Why not A? A checksum is a fixed-size error check; it does not overflow from retries.

G8C07

Which of the following narrow-band digital modes can receive signals with very low signal-to-noise ratios?

  1. A MSK144
  2. B FT8
  3. C AMTOR
  4. D MFSK32
Show the answer and explanation

Correct answer: B. FT8

Why B is right. B. FT8 can decode signals with very low signal-to-noise ratios.

FT8 sends slowly, uses narrow tones and adds strong error-correcting code. That lets it decode signals well below the noise you can hear, around 20 dB under it in a typical SSB bandwidth.

Why not C? AMTOR is an older error-checking mode that needs a much stronger signal.

G8C08

Which of the following statements is true about PSK31?

  1. A Upper case letters are sent with more power
  2. B Upper case letters use longer Varicode bit sequences and thus slow down transmission
  3. C Error correction is used to ensure accurate message reception
  4. D Higher power is needed as compared to RTTY for similar error rates
Show the answer and explanation

Correct answer: B. Upper case letters use longer Varicode bit sequences and thus slow down transmission

Why B is right. B. Varicode gives the shortest patterns to the most common characters, and capitals are much rarer than lowercase in normal text.

PSK31 uses Varicode, a character code where common characters get short bit patterns. So typing in all capitals is slower.

Why not A? PSK31 sends every character at the same power; only the length of the code differs.

G8C09

Which is true of mesh network microwave nodes?

  1. A Having more nodes increases signal strengths
  2. B If one node fails, a packet may still reach its target station via an alternate node
  3. C Links between two nodes in a network may have different frequencies and bandwidths
  4. D More nodes reduce overall microwave out of band interference
Show the answer and explanation

Correct answer: B. If one node fails, a packet may still reach its target station via an alternate node

Why B is right. B. Each node links to several others, so routing software can steer a packet around a dead node.

A mesh network links many nodes, each connected to several others. Software finds a route through the web of links, so no single node is a weak point.

Why not A? Adding nodes adds paths, but it does not make each signal stronger.

G8C10

How does forward error correction (FEC) allow the receiver to correct data errors?

  1. A By controlling transmitter output power for optimum signal strength
  2. B By using the Varicode character set
  3. C By transmitting redundant information with the data
  4. D By using a parity bit with each character
Show the answer and explanation

Correct answer: C. By transmitting redundant information with the data

Why C is right. C. The extra bits are built from the data by a known rule, so the receiver can work out which bits noise flipped and fix them.

FEC stands for forward error correction. No request to resend is needed, which helps on fading or one-way links.

Why not D? A single parity bit can detect some errors but cannot tell which bit to fix.

G8C11

How are the two separate frequencies of a Frequency Shift Keyed (FSK) signal identified?

  1. A Dot and dash
  2. B On and off
  3. C High and low
  4. D Mark and space
Show the answer and explanation

Correct answer: D. Mark and space

Why D is right. D. The two FSK frequencies are called mark and space.

These names come from early telegraph printers. Mark is one frequency and space is the other. In RTTY, the signal switches between them to send the bits of each character.

Why not A? Dot and dash are the elements of Morse code, not FSK frequencies.

G8C12

Which type of code is used for sending characters in a PSK31 signal?

  1. A Varicode
  2. B Viterbi
  3. C Volumetric
  4. D Binary
Show the answer and explanation

Correct answer: A. Varicode

Why A is right. A. PSK31 sends characters using Varicode.

Varicode gives each character a bit pattern whose length depends on how often it is used. Common letters get short patterns, so normal text moves faster. Two zero bits in a row mark the gap between characters.

Why not B? Viterbi is a method for decoding error-correcting codes, not a character code.

G8C13

What is indicated on a waterfall display by one or more vertical lines on either side of a data mode or RTTY signal?

  1. A Long path propagation
  2. B Backscatter propagation
  3. C Insufficient modulation
  4. D Overmodulation
Show the answer and explanation

Correct answer: D. Overmodulation

Why D is right. D. Extra vertical lines beside a data signal on a waterfall point to overmodulation.

A clean data signal shows as a tidy trace of a set width. Too much audio drive distorts it and creates extra frequencies. Those appear as fainter lines on each side, spreading into nearby channels.

Why not C? Too little modulation makes a weak trace; it does not add side lines.

G8C14

Which of the following describes a waterfall display?

  1. A Frequency is horizontal, signal strength is vertical, time is intensity
  2. B Frequency is vertical, signal strength is intensity, time is horizontal
  3. C Frequency is horizontal, signal strength is intensity, time is vertical
  4. D Frequency is vertical, signal strength is horizontal, time is intensity
Show the answer and explanation

Correct answer: C. Frequency is horizontal, signal strength is intensity, time is vertical

Why C is right. C. Each new row is one snapshot of the band, so time builds up vertically as rows scroll, while brightness or color shows strength.

Frequency runs left to right across the display. Older rows scroll down like falling water.

Why not A? On a waterfall, the vertical direction shows time, not signal strength.

G8C15

What does an FT8 signal report of +3 mean?

  1. A The signal is 3 times the noise level of an equivalent SSB signal
  2. B The signal is S3 (weak signals)
  3. C The signal-to-noise ratio is equivalent to +3dB in a 2.5 kHz bandwidth
  4. D The signal is 3 dB over S9
Show the answer and explanation

Correct answer: C. The signal-to-noise ratio is equivalent to +3dB in a 2.5 kHz bandwidth

Why C is right. C. FT8 scales its noise measurement to a standard 2.5 kHz width so reports compare across stations, and +3 is 3 dB above that noise.

FT8 software reports how far a signal is above or below the noise, in dB. A report of +3 is a strong FT8 signal.

Why not D? FT8 reports are signal-to-noise numbers, not S-meter readings.

G8C16

Which of the following provide digital voice modes?

  1. A WSPR, MFSK16, and EasyPAL
  2. B FT8, FT4, and FST4
  3. C Winlink, PACTOR II, and PACTOR III
  4. D DMR, D-STAR, and SystemFusion
Show the answer and explanation

Correct answer: D. DMR, D-STAR, and SystemFusion

Why D is right. D. All three digitize your voice, send it as data, and turn it back into audio at the receiver.

DMR, D-STAR and System Fusion are common on VHF and UHF radios and repeaters.

Why not B? FT8, FT4 and FST4 send short text messages, not voice.
