T8D: Non-voice and digital communications: image signals and definition of NTSC, CW, packet radio, PSK, APRS, error detection and correction, amateur radio networking, DMR, WSJT modes, Broadband-Hamnet

Group T8D of the Technician pool (2026–2030) has 12 active questions. One of them is on every Technician exam. Each is shown word for word; open it to see the correct answer and our explanation.

T8D01

Which of the following is a digital communications mode?

  1. A Packet radio
  2. B IEEE 802.11
  3. C FT8
  4. D All these choices are correct
Show the answer and explanation

Correct answer: D. All these choices are correct

Why D is right. D. All these choices are correct.

A digital mode sends information as numbers, usually ones and zeros. Packet radio sends data in blocks. IEEE 802.11 is the Wi-Fi standard, which hams can use on some shared bands. FT8 sends short data messages. All three are digital.

T8D02

What is FT8?

  1. A A wideband FM voice mode
  2. B A digital mode capable of low signal-to-noise operation
  3. C An eight-channel multiplex mode for FM repeaters
  4. D A digital slow-scan TV mode with forward error correction and automatic color compensation
Show the answer and explanation

Correct answer: B. A digital mode capable of low signal-to-noise operation

Why B is right. B. FT8 is a digital mode that works with low signal-to-noise ratios.

Signal-to-noise ratio compares how strong a signal is to the background noise. FT8 sends short, fixed-length messages in timed turns, and computer software decodes them. It can decode signals too weak to hear by ear, which makes long-distance contacts possible with low power.

Why not A? FT8 is a narrow data mode, not a voice mode.

T8D03

What kind of data can be transmitted by APRS?

  1. A GPS position data
  2. B Text messages
  3. C Weather data
  4. D All these choices are correct
Show the answer and explanation

Correct answer: D. All these choices are correct

Why D is right. D. All these choices are correct.

APRS stands for Automatic Packet Reporting System. It sends short data packets that can hold GPS position, text messages and weather station readings. Other APRS stations and internet sites can show the data on maps.

T8D04

What is meant by the term "NTSC?"

  1. A A digital transmission standard for encrypting data
  2. B A special mode for satellite uplink
  3. C An analog fast-scan color TV signal
  4. D A frame compression scheme for TV signals
Show the answer and explanation

Correct answer: C. An analog fast-scan color TV signal

Why C is right. C. NTSC is an analog fast-scan color TV signal.

NTSC is the analog color TV standard used for broadcast TV in the US for many years. Hams who send analog fast-scan TV often use this same format, so common TV sets and cameras can be used.

Why not A? NTSC is analog and does not encrypt anything.

T8D05

Which of the following is an application of APRS?

  1. A Providing real-time tactical digital communications in conjunction with a map showing the locations of stations
  2. B Automatically showing the number of packets transmitted via PACTOR during a specific time interval
  3. C Providing voice over internet connection between repeaters
  4. D Providing information on the number of stations signed into a repeater
Show the answer and explanation

Correct answer: A. Providing real-time tactical digital communications in conjunction with a map showing the locations of stations

Why A is right. A. APRS can give real-time tactical digital communications with a map of station locations.

APRS stations send their position and short messages. Software places each station on a map and updates it as new packets arrive. During events or emergencies, this shows at a glance where everyone is and lets them send quick text messages.

Why not C? Linking repeaters by voice over the internet is done by systems like IRLP or EchoLink, not APRS.

T8D06

What does the abbreviation "PSK" mean?

  1. A Pulse Shift Keying
  2. B Phase Shift Keying
  3. C Packet Sampled Keying
  4. D Power Sampled Keying
Show the answer and explanation

Correct answer: B. Phase Shift Keying

Why B is right. B. PSK stands for Phase Shift Keying.

Every radio wave has a phase, which marks where it is in its up-and-down cycle. PSK sends data by shifting that phase at set moments. The receiver watches for the shifts and turns them back into data.

Why not A? The P stands for phase, not pulse.

T8D07

Which of the following describes DMR?

  1. A A technique for time-multiplexing two digital voice signals on a single 12.5 kHz repeater channel
  2. B An automatic position tracking mode for FM mobiles communicating through repeaters
  3. C An automatic computer logging technique for hands-off logging when communicating while operating a vehicle
  4. D A digital technique for transmitting on two repeater inputs simultaneously for automatic error correction
Show the answer and explanation

Correct answer: A. A technique for time-multiplexing two digital voice signals on a single 12.5 kHz repeater channel

Why A is right. A. DMR fits two digital voice signals on one 12.5 kHz repeater channel by time-multiplexing.

Time-multiplexing means taking turns very quickly. A DMR repeater splits time into two repeating slots. One conversation uses the first slot and another uses the second. They switch so fast that both sound continuous, and the channel carries two talk paths.

Why not D? DMR uses one repeater channel, not two repeater inputs at once.

T8D08

Which of the following is included in packet radio transmissions?

  1. A A checksum that permits error detection
  2. B A header that contains the call sign of the station to which the information is being sent
  3. C Automatic repeat request in case of error
  4. D All these choices are correct
Show the answer and explanation

Correct answer: D. All these choices are correct

Why D is right. D. All these choices are correct.

Each packet carries a header with call signs, including the station it is going to. It also carries a checksum, a number worked out from the data. The receiver checks the number. If it does not match, the receiver can ask for the packet again, which is automatic repeat request.

T8D09

What is CW?

  1. A A type of electromagnetic propagation
  2. B A digital mode used primarily on 2-meter FM
  3. C Error correction for digital transmission using code words
  4. D Another name for a Morse code transmission
Show the answer and explanation

Correct answer: D. Another name for a Morse code transmission

Why D is right. D. CW is another name for a Morse code transmission.

CW stands for continuous wave. A transmitter sends a steady, unchanging wave, and the operator turns it on and off in the dots and dashes of Morse code. Hams use CW to mean Morse code sent this way.

Why not B? CW is used on almost every band, and it is not a 2-meter FM digital mode.

T8D10

Which of the following operating activities is supported by digital mode software in the WSJT-X software suite?

  1. A Earth-Moon-Earth
  2. B Weak signal propagation beacons
  3. C Meteor scatter
  4. D All these choices are correct
Show the answer and explanation

Correct answer: D. All these choices are correct

Why D is right. D. All these choices are correct.

WSJT-X is free software that offers several digital modes, each built for a different kind of hard path. Some modes help with signals bounced off the Moon, called Earth-Moon-Earth. Others handle short bursts from meteor trails, and others send weak beacon signals to study propagation.

T8D11

What is the role of ARQ in a transmission system?

  1. A A special transmission format limited to video signals
  2. B A system used to encrypt command signals to an amateur radio satellite
  3. C An error correction method in which the receiving station detects errors and sends a request for retransmission
  4. D A method of compressing data using autonomous reiterative Q codes prior to final encoding
Show the answer and explanation

Correct answer: C. An error correction method in which the receiving station detects errors and sends a request for retransmission

Why C is right. C. ARQ is error correction in which the receiver detects errors and asks for a resend.

ARQ stands for automatic repeat request. The receiving station checks each block of data. If a block arrives damaged, it sends back a request, and the sender transmits that block again. This repeats until the data comes through correctly.

Why not B? ARQ fixes errors. It is not a way to encrypt commands.

T8D12

Which of the following best describes an amateur radio mesh network?

  1. A An amateur-radio data network using commercial Wi-Fi equipment with modified firmware
  2. B A wide-bandwidth digital voice mode employing DMR protocols
  3. C An amateur-radio satellite communications network using modified commercial satellite TV hardware
  4. D An internet linking protocol allowing communication through repeaters around the world
Show the answer and explanation

Correct answer: A. An amateur-radio data network using commercial Wi-Fi equipment with modified firmware

Why A is right. A. A ham mesh network is a data network built from commercial Wi-Fi equipment with modified firmware.

Firmware is the built-in software that runs a device. Hams load new firmware into ordinary Wi-Fi routers so they can run under amateur rules and link to each other. Each node passes data along to the next, forming a web of connections.

Why not B? A mesh network carries data between computers, not DMR digital voice.
