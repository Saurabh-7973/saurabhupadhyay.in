E8D: Keying defects and overmodulation of digital signals; digital codes; spread spectrum

Group E8D of the Amateur Extra pool (2024–2028) has 11 active questions. One of them is on every Amateur Extra exam. Each is shown word for word; open it to see the correct answer and our explanation.

E8D01

Why are received spread spectrum signals resistant to interference?

  1. A Signals not using the spread spectrum algorithm are suppressed in the receiver
  2. B The high power used by a spread spectrum transmitter keeps its signal from being easily overpowered
  3. C Built-in error correction codes minimize interference
  4. D If the receiver detects interference, it will signal the transmitter to change frequencies
Show the answer and explanation

Correct answer: A. Signals not using the spread spectrum algorithm are suppressed in the receiver

Why A is right. A. The receiver un-spreads only signals built with its own spreading code, so other signals stay spread out and weak.

A spread spectrum transmitter spreads its signal over a wide band using a pseudorandom code. The receiver applies the same code, which collapses the wanted signal back into a narrow, strong one. Any signal without that code gets spread out by the same step. Its energy then lands mostly outside the narrow filter, so it is pushed down.

Why not B? Spread spectrum signals are usually low power per hertz; the protection comes from the code, not from strength.

E8D02

What spread spectrum communications technique uses a high-speed binary bit stream to shift the phase of an RF carrier?

  1. A Frequency hopping
  2. B Direct sequence
  3. C Binary phase-shift keying
  4. D Phase compandored spread spectrum
Show the answer and explanation

Correct answer: B. Direct sequence

Why B is right. B. Direct sequence mixes the data with a fast pseudorandom bit stream that flips the carrier's phase, spreading it wide.

The spreading code runs many times faster than the data. Each fast bit, called a chip, shifts the carrier's phase. Those rapid shifts spread the signal across a wide band. The receiver uses the same chip sequence to undo the spreading. The faster the chip rate, the wider the signal.

Why not C? Binary phase-shift keying is the basic phase-flip modulation; by itself it is not a spreading technique.

E8D03

Which describes spread spectrum frequency hopping?

  1. A If interference is detected by the receiver, it will signal the transmitter to change frequencies
  2. B RF signals are clipped to generate a wide band of harmonics which provides redundancy to correct errors
  3. C A binary bit stream is used to shift the phase of an RF carrier very rapidly in a pseudorandom sequence
  4. D Rapidly varying the frequency of a transmitted signal according to a pseudorandom sequence
Show the answer and explanation

Correct answer: D. Rapidly varying the frequency of a transmitted signal according to a pseudorandom sequence

Why D is right. D. Interference on any one channel touches only a small part of a hopping signal, because its frequency keeps changing in a pseudorandom pattern both stations share.

Transmitter and receiver share the same hop pattern and timing. They jump together many times each second. A listener on any one channel hears only brief bursts. Interference on one channel ruins only a small part of the data, which error correction can often repair. The hops follow the plan; they are not triggered by interference.

Why not C? Using a fast bit stream to shift the carrier's phase describes direct sequence, not frequency hopping.

E8D04

What is the primary effect of extremely short rise or fall time on a CW signal?

  1. A More difficult to copy
  2. B The generation of RF harmonics
  3. C The generation of key clicks
  4. D More difficult to tune
Show the answer and explanation

Correct answer: C. The generation of key clicks

Why C is right. C. A carrier that turns on or off almost instantly produces wide sidebands, heard on nearby frequencies as key clicks.

A sharp edge in the signal's envelope holds energy at many frequencies. Each time the key closes or opens, that energy spreads well beyond the CW signal. Operators listening nearby hear a click or thump with every keystroke. The fix is to shape the edges so the carrier rises and falls over a few milliseconds.

Why not B? Harmonics are multiples of the carrier frequency caused by nonlinearity; key clicks sit close to the signal itself.

E8D05

What is the most common method of reducing key clicks?

  1. A Increase keying waveform rise and fall times
  2. B Insert low-pass filters at the transmitter output
  3. C Reduce keying waveform rise and fall times
  4. D Insert high-pass filters at the transmitter output
Show the answer and explanation

Correct answer: A. Increase keying waveform rise and fall times

Why A is right. A. Slowing the rise and fall of each keyed element smooths the envelope, which removes the sharp edges that cause clicks.

Key clicks come from sidebands created by abrupt switching. If the carrier ramps up and down over a few milliseconds, those sidebands shrink. Transmitters do this with a shaping circuit or in software. A low-pass filter on the output cannot help, because clicks are close to the operating frequency and pass right through it.

Why not B? A low-pass output filter removes harmonics far above the signal, but clicks are near the signal and pass through it.

E8D06

What is the advantage of including parity bits in ASCII characters?

  1. A Faster transmission rate
  2. B Signal-to-noise ratio is improved
  3. C A larger character set is available
  4. D Some types of errors can be detected
Show the answer and explanation

Correct answer: D. Some types of errors can be detected

Why D is right. D. A parity bit makes the count of 1s even or odd, so a single flipped bit breaks the pattern and shows an error.

With even parity, the sender adds a 1 or a 0 so each character has an even number of 1 bits. The receiver counts them. An odd count means something changed in transit. Parity cannot tell which bit was wrong, and two flipped bits cancel out and go unnoticed. That is why it detects only some errors.

Why not A? A parity bit adds one more bit per character, so it slightly slows the data, not speeds it up.

E8D07

What is a common cause of overmodulation of AFSK signals?

  1. A Excessive numbers of retries
  2. B Excessive frequency deviation
  3. C Bit errors in the modem
  4. D Excessive transmit audio levels
Show the answer and explanation

Correct answer: D. Excessive transmit audio levels

Why D is right. D. Driving the transmitter with too much audio pushes it into distortion, which overmodulates an AFSK signal.

AFSK (audio frequency-shift keying) feeds audio tones into an SSB or FM transmitter. If the audio level is too high, the transmitter's audio stages or its automatic level control get pushed too hard. The tones distort and create extra products that widen the signal. Set the audio so the transmitter runs below the point where ALC starts acting hard.

Why not C? Bit errors happen at the receiving end; they do not change how loudly the transmitter is driven.

E8D08

What parameter evaluates distortion of an AFSK signal caused by excessive input audio levels?

  1. A Signal-to-noise ratio
  2. B Baud error rate
  3. C Repeat Request Rate (RRR)
  4. D Intermodulation Distortion (IMD)
Show the answer and explanation

Correct answer: D. Intermodulation Distortion (IMD)

Why D is right. D. Overdriven audio mixes the tones together into new, unwanted frequencies, and IMD measures how strong those products are.

Intermodulation distortion (IMD) happens when two or more tones pass through a stage that is not linear. The stage creates sum and difference products, some close to the wanted tones. On a PSK or other digital signal those products widen the signal and splatter onto neighbors. Many digital-mode programs display an IMD reading for this reason.

Why not A? Signal-to-noise ratio compares the signal with background noise; it does not measure distortion the transmitter adds.

E8D09

What is considered an acceptable maximum IMD level for an idling PSK signal?

  1. A +5 dB
  2. B +10 dB
  3. C +15 dB
  4. D -30 dB
Show the answer and explanation

Correct answer: D. -30 dB

Why D is right. D. Distortion products 30 dB or more below the main signal are small enough to keep a PSK signal clean and narrow.

IMD is reported as the strength of the unwanted products relative to the wanted signal, so it is a negative number in dB. The more negative, the cleaner. A value near -30 dB is a common target for an idling PSK signal. Readings closer to zero, like -20 dB, mean the transmitter is being overdriven.

Why not A? A positive IMD value would mean the distortion is stronger than the signal itself, which is never acceptable.

E8D10

What are some of the differences between the Baudot digital code and ASCII?

  1. A Baudot uses 4 data bits per character, ASCII uses 7 or 8; Baudot uses 1 character as a letters/figures shift code, ASCII has no letters/figures code
  2. B Baudot uses 5 data bits per character, ASCII uses 7 or 8; Baudot uses 2 characters as letters/figures shift codes, ASCII has no letters/figures shift code
  3. C Baudot uses 6 data bits per character, ASCII uses 7 or 8; Baudot has no letters/figures shift code, ASCII uses 2 letters/figures shift codes
  4. D Baudot uses 7 data bits per character, ASCII uses 8; Baudot has no letters/figures shift code, ASCII uses 2 letters/figures shift codes
Show the answer and explanation

Correct answer: B. Baudot uses 5 data bits per character, ASCII uses 7 or 8; Baudot uses 2 characters as letters/figures shift codes, ASCII has no letters/figures shift code

Why B is right. B. Baudot packs each character into 5 bits and uses LTRS and FIGS codes to switch sets; ASCII's 7 or 8 bits need no shift.

Five bits allow only 32 combinations, too few for letters, numbers and punctuation. Baudot solves this with two special characters: one switches to the letters set, the other to the figures set. ASCII uses 7 bits, giving 128 codes, or 8 bits in extended form. That is enough room to give every character its own code.

Why not A? Baudot uses 5 data bits, not 4, and it needs two shift codes, one for each set.

E8D11

What is one advantage of using ASCII code for data communications?

  1. A It includes built-in error correction features
  2. B It contains fewer information bits per character than any other code
  3. C It is possible to transmit both uppercase and lowercase text
  4. D It uses one character as a shift code to send numeric and special characters
Show the answer and explanation

Correct answer: C. It is possible to transmit both uppercase and lowercase text

Why C is right. C. ASCII has enough codes to give upper and lower case letters their own values, so both can be sent.

With 7 bits, ASCII has 128 codes. That covers capital letters, small letters, digits, punctuation and control characters. Older 5-bit codes like Baudot have room for only one case of letters. ASCII by itself does not correct errors; that needs extra coding or a protocol.

Why not D? Using a shift code to reach numbers and symbols is how Baudot works, not ASCII.
