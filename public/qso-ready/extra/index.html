Amateur Extra question pool 2024–2028, explained

Element 4. The exam has 50 questions, one from each group below, and you pass with 37 correct. This pool is used for exams from 2024-07-01 to 2028-06-30. It has 599 active questions. Each group page shows every question in the group with the correct answer and our explanation (2 are still in review).
