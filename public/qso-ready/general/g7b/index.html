G7B: Digital circuits; amplifiers and oscillators

Group G7B of the General pool (2023–2027) has 11 active questions. One of them is on every General exam. Each is shown word for word; open it to see the correct answer and our explanation.

G7B01

What is the purpose of neutralizing an amplifier?

  1. A To limit the modulation index
  2. B To eliminate self-oscillations
  3. C To cut off the final amplifier during standby periods
  4. D To keep the carrier on frequency
Show the answer and explanation

Correct answer: B. To eliminate self-oscillations

Why B is right. B. Neutralizing cancels feedback that would make the amplifier oscillate on its own.

Inside an amplifying device, a little output signal leaks back to the input through internal capacitance. If that leak arrives with the wrong timing, the stage can start making its own signal, called self-oscillation. Neutralizing feeds back an equal signal of opposite phase to cancel the leak.

Why not D? Keeping the carrier on frequency is the job of the oscillator, not neutralization.

G7B02

Which of these classes of amplifiers has the highest efficiency?

  1. A Class A
  2. B Class B
  3. C Class AB
  4. D Class C
Show the answer and explanation

Correct answer: D. Class C

Why D is right. D. Class C has the highest efficiency of the four.

Efficiency means how much of the DC power becomes RF output instead of heat. Class C conducts for less than half of each cycle, so the device sits idle most of the time and wastes little power. Class A conducts all the time and is the least efficient.

Why not B? Class B conducts for about half the cycle, so it is better than A or AB but not as efficient as C.

G7B03

Which of the following describes the function of a two-input AND gate?

  1. A Output is high when either or both inputs are low
  2. B Output is high only when both inputs are high
  3. C Output is low when either or both inputs are high
  4. D Output is low only when both inputs are high
Show the answer and explanation

Correct answer: B. Output is high only when both inputs are high

Why B is right. B. 'AND' means input one and input two must both be high; a single low input holds the output low.

A logic gate works with two levels, high and low. Any other mix of inputs gives a low output.

Why not C? Low output when either input is high describes a NOR gate, not AND.

G7B04

In a Class A amplifier, what percentage of the time does the amplifying device conduct?

  1. A 100%
  2. B More than 50% but less than 100%
  3. C 50%
  4. D Less than 50%
Show the answer and explanation

Correct answer: A. 100%

Why A is right. A. A Class A device conducts for the whole cycle, 100% of the time.

Class A biases the transistor or tube so current always flows, even with no signal. This keeps the output a faithful copy of the input, with low distortion. The cost is poor efficiency, since power is used even when nothing is being amplified.

Why not B? More than 50% but less than 100% describes Class AB.

G7B05

How many states does a 3-bit binary counter have?

  1. A 3
  2. B 6
  3. C 8
  4. D 16
Show the answer and explanation

Correct answer: C. 8

Why C is right. C. Three bits can form 8 different patterns, so the counter has 8 states.

Each bit can be 0 or 1, so each added bit doubles the number of patterns. A 3-bit counter steps from 000 up to 111 and then starts over. That is 0 through 7, which is eight states.

states = 2^n, where n is the number of bits
n = 3
states = 2^3 = 2 × 2 × 2
states = 8
= 8

Why not A? 3 is the number of bits, not the number of patterns those bits can make.

G7B06

What is a shift register?

  1. A A clocked array of circuits that passes data in steps along the array
  2. B An array of operational amplifiers used for tri-state arithmetic operations
  3. C A digital mixer
  4. D An analog mixer
Show the answer and explanation

Correct answer: A. A clocked array of circuits that passes data in steps along the array

Why A is right. A. Its flip-flops share one clock, so each tick copies every stored bit into the next cell down the line.

A shift register is a row of memory cells, called flip-flops. It can turn a serial stream of bits into parallel form, or the other way around.

Why not C? A mixer combines two signals to make new frequencies; it does not store or step data.

G7B07

Which of the following are basic components of a sine wave oscillator?

  1. A An amplifier and a divider
  2. B A frequency multiplier and a mixer
  3. C A circulator and a filter operating in a feed-forward loop
  4. D A filter and an amplifier operating in a feedback loop
Show the answer and explanation

Correct answer: D. A filter and an amplifier operating in a feedback loop

Why D is right. D. The amplifier replaces the energy lost on each trip around the loop, and the filter lets only one frequency keep circulating.

The filter is often a coil and capacitor. Only the frequency that goes around the loop with the right phase builds up, and it becomes a steady sine wave.

Why not C? A feed-forward loop does not send output back to the input, so it cannot sustain an oscillation.

G7B08

How is the efficiency of an RF power amplifier determined?

  1. A Divide the DC input power by the DC output power
  2. B Divide the RF output power by the DC input power
  3. C Multiply the RF input power by the reciprocal of the RF output power
  4. D Add the RF input power to the DC output power
Show the answer and explanation

Correct answer: B. Divide the RF output power by the DC input power

Why B is right. B. Efficiency compares what you get, RF out, with what you pay for, DC power drawn from the supply.

For example, 60 W of RF from 100 W of DC input is 60% efficient. The rest becomes heat.

Why not A? Both terms in A are DC values, and the division is upside down.

G7B09

What determines the frequency of an LC oscillator?

  1. A The number of stages in the counter
  2. B The number of stages in the divider
  3. C The inductance and capacitance in the tank circuit
  4. D The time delay of the lag circuit
Show the answer and explanation

Correct answer: C. The inductance and capacitance in the tank circuit

Why C is right. C. Energy swaps back and forth between the coil and the capacitor at one natural rate, and that rate is the output frequency.

A tank circuit is an inductor and a capacitor connected together. Its natural frequency is called resonance. More inductance or more capacitance lowers that frequency.

Why not D? A lag circuit's time delay sets the frequency in an RC oscillator, not in an LC oscillator.

G7B10

Which of the following describes a linear amplifier?

  1. A Any RF power amplifier used in conjunction with an amateur transceiver
  2. B An amplifier in which the output preserves the input waveform
  3. C A Class C high efficiency amplifier
  4. D An amplifier used as a frequency multiplier
Show the answer and explanation

Correct answer: B. An amplifier in which the output preserves the input waveform

Why B is right. B. 'Linear' means the output is always the same multiple of the input, so the waveform's shape is kept.

Any change in amplitude at the input shows up the same way at the output. This matters for SSB and AM, where the information is carried in the signal's amplitude.

Why not C? Class C distorts the waveform, so it is not a linear amplifier.

G7B11

For which of the following modes is a Class C power stage appropriate for amplifying a modulated signal?

  1. A SSB
  2. B FM
  3. C AM
  4. D All these choices are correct
Show the answer and explanation

Correct answer: B. FM

Why B is right. B. FM is the mode where a Class C stage works well.

An FM signal has the same amplitude all the time; the information is in its frequency. Class C distorts amplitude, but that does no harm when amplitude carries nothing. SSB and AM carry information in amplitude, so they need a linear amplifier.

Why not A? SSB depends on amplitude changes, which a Class C stage would distort.
